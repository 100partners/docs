// what we built · setup notes for anyone who wants the same

claude code, running on its own always-on machine

we put claude code on a small cloud computer that runs 24/7. now you can open a terminal on your phone, type what you want, and claude builds it, saves it, and backs it up to github — no laptop, nothing running on your own device.

[01] the idea · in plain language

normally you run claude code on your own laptop. that means the laptop has to be open, awake, and with you. we moved it onto a vps instead — a small computer we rent in the cloud that never sleeps.

that one change unlocks a lot: the machine is always on, so long jobs keep running after you walk away. you reach it from any device — phone included — and every change claude makes is committed and pushed to github automatically, so nothing is ever lost.

[02] how it works · the flow

from typing on your phone to code saved on github, five steps:

1
open the terminal on your phone
any ssh app works. you connect over tailscale — a private network that links only your own devices to the box.
2
land on the vps — the machine called "hq"
a session opens inside tmux, so the work keeps running even if you close the phone or lose signal. reopen later and it's exactly where you left it.
3
tell claude what you want
plain english. "build me a page", "fix this", "set up a project". claude code plans it and does the work on the machine.
4
claude saves and backs up automatically
when a piece of work is done it commits and pushes to github on its own. full history, nothing lost, no manual "save" step.
5
publish, if it's a page
pages go live on docs.100.partners through github pages — this very page got here that way.
[03] the stack · tools we used
the vps ubuntu 24.04 lts
the rented cloud computer itself. small, cheap, and on 24/7. this is what "hq" is.
claude code v2.1.201
the ai agent that does the actual work — reading, writing, and running things on the machine from plain-english instructions.
tailscale private network
links only your own devices to the box over an encrypted network. the machine isn't left open to the public internet.
ssh the connection
the secure way you log in from a phone or laptop terminal. this is what your ssh app speaks.
tmux persistent sessions
keeps your session — and claude — running after you disconnect. close the phone, come back later, nothing was interrupted.
git + github cli gh
saves every change with history and backs it up to github automatically. also how new repos get created from the box.
node.js v22
the runtime claude code runs on. installed once, then forgotten about.
github pages docs.100.partners
turns a folder of html into a live website on our domain. how these overview pages get published.
[04] why it's useful · the benefits

no laptop needed. an ssh app and a few taps and you're building from anywhere.

your own phone or laptop stays clean. all the tools live on the vps, not your device.

tailscale means only your own devices can reach the machine — it isn't exposed to the open internet.
cheap + disposable

[05] ground rules · how claude behaves on the box

a few standing rules keep the setup safe and predictable, every project:

  • after any piece of work: commit and push automatically. never leave work unsaved.
  • never put secrets or passwords in a repo. they live in ignored files or get asked for.
  • stay inside the current project folder unless told otherwise.
  • explain everything in plain language — no jargon, short answers.
[06] want the same · the shape of it

the whole thing is five moving parts. at a high level:

# 1. rent a small vps (ubuntu 24.04) from any cloud host
# 2. put it on your tailscale network so only your devices reach it
# 3. install node, then claude code + the github cli
npm i -g @anthropic-ai/claude-code
claude # sign in once
gh auth login # connect github once
# 4. start work inside tmux so it survives disconnects
tmux new -s work && claude
# 5. from your phone: open an ssh app, connect, and talk to claude

that's the entire setup. not a developer? that's the point — you tell claude what you want in plain english and it handles the rest. happy to walk any friend through it.
